# telegram-cash-tracker
Telegram Cash Tracker

## Веб-панель

В двух терминалах запустите `make run-api` и `make run-web`.
Панель доступна по адресу http://localhost:3000. Зависимости фронтенда
устанавливаются командой `bun install` в `aps/web`.

Команда `make run-web` загружает общий `.env`: `API_BASE_URL` задаёт адрес
Go API (по умолчанию `http://localhost:8080`), `WEB_PORT` — порт панели
(по умолчанию `3000`). Сервер Bun проксирует запросы `/api/admin/spendings`
в Go API. Для работы панели нужен сервер Bun, а не только раздача `dist`.

Доступны список, фильтры, создание, редактирование и удаление расходов.
Участник указывается по внутреннему `users.id`: ручки получения списка
пользователей в API пока нет. Суммы — целые рубли. Даты отображаются
в часовом поясе браузера, последний день периода включается целиком.
Итог под таблицей относится только к текущей странице.

Проверка фронтенда: `bun run build` и `bun x --no-install tsc --noEmit`
из `aps/web`.
